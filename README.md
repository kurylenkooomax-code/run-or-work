# Біжи або працюй

Мобільний 3D-раннер у стилі Subway Surfers: котик (або кішка) у костюмі з ноутбуком тікає від боса з дедлайном. Бос біжить завжди, і якщо наздожене, котик іде працювати в офіс.

Версія 21 · жовтень 2026

## Як грати

- **Телефон:** свайпи. Вліво / вправо — змінити доріжку, вгору — стрибок, вниз — підкат.
- **Комп'ютер:** стрілки на клавіатурі.

Локації: офіс, вулиця, кав'ярня з горищем і кавовими річками, червоний міст із поворотом і вітром. Кожні 1000 м день змінюється ніччю. Є гардероб для котика й кішки, власний бізнес і магазин.

Грати за посиланням: `https://ЛОГІН.github.io/НАЗВА-РЕПОЗИТОРІЮ/` (з'явиться після кроку «Увімкнути GitHub Pages» нижче).

## Файли

| Файл | Що в ньому |
| --- | --- |
| `index.html` | Сторінка гри: стилі, меню, табло, завантаження інших файлів |
| `core.js` | Збереження прогресу, гаманець, економіка бізнесу |
| `texts.js` | Усі тексти українською та англійською |
| `wardrobe.js` | Одяг і 3D-модель котика й кішки |
| `world.js` | 3D-світ: локації, перешкоди, бафи, міст, день і ніч |
| `game.js` | Логіка забігу, камера, екрани меню |
| `opys-hry.md` | Повний опис гри: механіки, ціни, технічні деталі |

Файли завантажуються по черзі: `core.js` → `texts.js` → `wardrobe.js` → `world.js` → `game.js`. Для 3D використовується three.js r128 (з cdnjs), тому для гри потрібен інтернет.

## Як залити на GitHub

1. На github.com натисни **New** (новий репозиторій), дай йому назву (наприклад, `run-or-work`), обери **Public** і створи.
2. У репозиторії натисни **Add file → Upload files**.
3. Розпакуй архів і перетягни **вміст папки** (усі файли, а не саму папку), щоб `index.html` лежав у корені репозиторію.
4. Натисни **Commit changes**.

## Увімкнути GitHub Pages

1. У репозиторії відкрий **Settings → Pages**.
2. У **Source** обери **Deploy from a branch**, гілку **main** і папку **/ (root)**, натисни **Save**.
3. Зачекай 1–2 хвилини й онови сторінку: угорі з'явиться посилання на гру.

На безкоштовному тарифі GitHub Pages працює лише для публічних репозиторіїв.

## Важливо знати

- Прогрес (монети, одяг, рекорд) зберігається в браузері окремо для кожного сайту. Тому на GitHub Pages прогрес свій, не той, що в грі на Claude.
- Щоб оновити гру, завантаж нові файли з тими самими іменами через **Add file → Upload files**: вони замінять старі.
