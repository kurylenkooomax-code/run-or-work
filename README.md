# Біжи або працюй

Мобільний 3D-раннер у стилі Subway Surfers: котик (або кішка) у костюмі з ноутбуком тікає від боса з дедлайном. Бос біжить завжди, і якщо наздожене, котик іде працювати в офіс.

Версія 69 · жовтень 2026

## Як грати

- **Телефон:** свайпи. Вліво / вправо — змінити доріжку, вгору — стрибок, вниз — підкат (у басейні — пірнути під будь-що).
- **Комп'ютер:** стрілки на клавіатурі.

Локації: офіс, вулиця, кав'ярня з горищем і кавовими річками, червоний міст із поворотом і вітром, парк. Після кожного мосту: серпантин угору → роздягальня (котик перевдягається в плавки) → тераса, де дорога обривається → падіння в басейн і заплив з перешкодами → вихід по пандусу → пляж → аеропорт (знову в костюмі) → рукав → салон літака зі зльотом → туалет, де котика засмоктує унітаз → труба (котик крихітний, біжить угору) → кран: крапля переносить котика на стіл → стіл → порт USB-C ноутбука → поки що назад у парк. Кожні 1000 м день змінюється ніччю. Є гардероб для котика й кішки, власний бізнес і магазин.

Грати за посиланням: `https://ЛОГІН.github.io/НАЗВА-РЕПОЗИТОРІЮ/` (з'явиться після кроку «Увімкнути GitHub Pages» нижче).

## Як залити на GitHub

1. У репозиторії натисни **Add file → Upload files**.
2. Розпакуй архів і перетягни **вміст папки** (усі файли й папку `locations` разом), щоб `index.html` лежав у корені репозиторію.
3. Натисни **Commit changes**. Файли з тими самими іменами заміняться, нові папки (`airport`, `plane`, `mini`) додадуться.

## Увімкнути GitHub Pages

1. У репозиторії відкрий **Settings → Pages**.
2. У **Source** обери **Deploy from a branch**, гілку **main** і папку **/ (root)**, натисни **Save**.
3. Зачекай 1–2 хвилини й онови сторінку: угорі з'явиться посилання на гру.

## Що нового у версії 69 (оптимізація й анімації)

- **Менше ривків.** Новий шматок світу будується вдвічі швидше, а перешкоди й монетки на ньому ставляться наступним кадром. Людей (працівників, перехожих) і крісла в літаку гра будує один раз і далі копіює. Найгірший кадр на слабкому процесорі: офіс 415 → 97 мс, парк 167 → 65 мс, кав'ярня 101 → 40 мс, салон 87 → 39 мс.
- **Без фризів на нових локаціях.** Усі шейдери (графічні програми) компілюються ще в меню, тому посеред забігу нових більше не з'являється. Пара над кавою більше не компілюється заново в кожній кав'ярні.
- **Менше роботи для відеокарти.** Монетки малюються однією групою (було 60–80 викликів малювання на кадр). Котик і бос зібрані з меншої кількості частин (90 → 26 викликів), нерухомі люди в аеропорту злиті з декором. Разом: офіс 364 → 248, кав'ярня 393 → 282, парк 187 → 73, аеропорт 322 → 150 викликів.
- **Роздільність до 1,5×** (було 2×). Якщо FPS стабільно падає, гра сама знижує роздільність до 1×.
- **Анімації:** коза на серпантині знову виляє хвостом, лампочки в кав'ярні мерехтять кожна у своєму ритмі, збиті парасоля й кіоск у парку перекидаються, а не пролітають крізь камеру.

## Що нового у версії 68

- **Аеропорт → літак став зрозумілим.** Біля виходу A1 — посадка: табло «ПОСАДКА · РЕЙС KA-404», працівники авіакомпанії за стійками, турнікети посадкових талонів на кожній доріжці (відчиняються й світяться зеленим), а за склом ліворуч видно літак з рукавом. Сам рукав тепер скляний, і камера в ньому дивиться трохи вгору: попереду видно ніс літака — кабіну пілотів, логотип KOT-AIR, відчинені двері, крила й хвіст.
- **Літак → туалет став зрозумілим.** У кінці салону висять вказівники «WC ↑ 90 м», «60 м», «30 м». Перед туалетом — черга пасажирів (вони озираються на котика), двері від'їжджають, коли котик підбігає, поруч таблички «ВІЛЬНО». Бос: «Без черги?! Нахаба!»
- Нові підказки вгорі екрана на цих переходах.

## Що нового у версії 67

- **Кнопка «Грати» більше не «мовчить».** Раніше, якщо на GitHub не потрапила папка `locations` (або телефон тримав старі копії файлів), меню працювало, а «Грати» нічого не робила. Тепер гра шукає файли локацій і в папках, і просто поруч з `index.html`, завжди бере свіжі файли, а якщо чогось бракує — показує, яких саме файлів немає.
- Якщо під час старту трапиться помилка, з'явиться екран з її текстом — його можна сфотографувати й надіслати.
- Кав'ярня малюється швидше: вивіски, вікна й фасади зливаються разом з рештою декору (було ~900 викликів малювання на кадр, стало ~400).

## Якщо гра пише «Бракує файлів гри»

Відкрий репозиторій на GitHub і перевір, що поруч з `index.html` лежить папка `locations`, а в ній 12 папок: office, street, cafe, bridge, park, serpentine, locker, pool, beach, airport, plane, mini. Якщо папок немає — перетягни папку `locations` з архіву у вікно **Add file → Upload files** (з комп'ютера, у браузері Chrome або Edge: телефон не вміє завантажувати папки). Можна й простіше: завантажити всі `.js` файли з папок `locations/…` просто в корінь репозиторію поруч з `index.html` — версія 67 знайде їх і там.

## Важливо знати

- Прогрес (монети, одяг, рекорд) зберігається в браузері окремо для кожного сайту. Тому на GitHub Pages прогрес свій, не той, що в грі на Claude.
- Серпантин з'являється після першого мосту, приблизно на 2,5–3 км забігу. Аеропорт — одразу після пляжу, приблизно на 4–5 км.
- Після оновлення GitHub Pages може ще кілька хвилин показувати стару версію. Якщо так — онови сторінку ще раз.
